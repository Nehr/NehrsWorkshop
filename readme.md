# My mods

## Trinity Seating – Pickup Truck Middle Seat

Trinity Seating adds a functional front middle seat to vanilla pickup-style vehicles, allowing three passengers.

### Features

- Adds a usable front middle seat to supported pickup-style vehicles
- Seat switching between driver, middle, and passenger seats
- Proper exiting from the passenger side
- Only changes supported vanilla pickup truck and Bulldriver variants

### Compatibility

- Vanilla-friendly
- Safe to add to existing saves
- Does not override shared base vehicle templates
- May conflict with mods that also edit supported vanilla pickup vehicle scripts

### Notes

- This mod only affects supported vanilla pickup truck and Bulldriver variants
- No balance or performance changes
