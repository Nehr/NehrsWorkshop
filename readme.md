# My mods

## Trinity Seating – Pickup Truck Middle Seat

Trinity Seating adds a functional front middle seat to the vanilla pickup truck, allowing three passengers.

### Features

- Adds a usable front middle seat to the pickup truck
- Seat switching between driver, middle, and passenger seats
- Proper exiting from the passenger side
- Does not affect any other vehicles

### Compatibility

- Vanilla-friendly
- Safe to add to existing saves
- No overrides of base vehicle templates

### Notes

- This mod only affects the standard pickup truck
- No balance or performance changes
